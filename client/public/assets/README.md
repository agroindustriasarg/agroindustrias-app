# Assets Directory

## Logo de la Empresa

Para que el PDF del reporte de Servicios muestre el logo de la empresa, coloca el archivo de imagen del logo con el nombre `logo.png` en esta carpeta.

### Especificaciones recomendadas:
- **Formato:** PNG (con transparencia preferiblemente)
- **Nombre:** `logo.png`
- **Tamaño recomendado:** 200x200 píxeles o similar (se redimensionará automáticamente)
- **Ubicación:** `client/public/assets/logo.png`

El logo debe ser la imagen de "Agroindustrias Argentinas SRL" que aparece en tu identidad corporativa.

Si el archivo no está presente, el PDF se generará sin logo pero con el resto de la información (encabezado, fecha, filtros, etc.).
